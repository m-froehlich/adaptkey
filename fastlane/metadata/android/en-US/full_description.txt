AdaptKey is an adaptive Android keyboard (IME) that learns how you type - built for privacy first.

Provably offline. No phoning home.

AdaptKey has no internet permission at all. This is not a promise you have to take on faith - it is enforced by Android and verifiable by anyone: there is no INTERNET permission in the app manifest, so the operating system makes it impossible for the app to open a network connection. No telemetry, no analytics, no "anonymous usage statistics", no ads, no cloud sync.

* No internet permission - kernel-enforced, not a checkbox you trust.
* No storage permission - the optional local AI model is imported through the system file picker, which grants access to just that one file.
* Everything runs on-device. Dictionaries, autocorrect, language detection and the optional mini-LLM all execute locally.
* Free software, licensed under GPL-3.0-or-later - audit every line yourself.

Features

* Gboard-style QWERTZ/QWERTY layout with freely configurable key proportions (space bar, comma, full stop, backspace), a persistent number row, and per-key long-press secondary symbols.
* Learns your touch pattern. A per-key personal offset model adapts hit detection to how you actually tap; an optional calibration step seeds it.
* Smart suggestions and autocorrect from a personal on-device dictionary, with a stabilised suggestion bar, a "keep as typed" escape hatch, and one-tap post-commit undo.
* Real multilingual dictionaries as optional downloadable language packs (German, English and Greek bundled to start with, more to follow), with on-device language detection that switches the whole lexicon per language.
* Greek input with its own layout and accent long-press.
* German capitalisation done right: sentence starts, nouns vs. proper nouns, hyphen segments, the e-mail-salutation comma rule, abbreviations, and a configurable shift-grace window.
* Retroactive fixes: missed-space word split and spurious-space merge, driven by touch ambiguity.
* Gestures: swipe to delete a whole word, swipe down to dismiss, drag a suggestion to trash to blacklist it, word-end shift for casing/camelCase.
* Emoji panel with recents and a live keyword search (English and German).
* Optional on-device mini-LLM (opt-in, work in progress): when the on-device dictionary is uncertain, a small local language model can improve predictions. It is never bundled or downloaded by the app - you import it yourself via the system file picker, and it stays fully offline afterwards.
* Backup and restore your personal learned words, settings and blacklist as a single file.

AdaptKey is under active development. Feedback and bug reports are welcome on the source repository.
