# Plan Documents

- read `doc/plan/README.md` before creating, moving, renaming or referencing a plan; it defines the lifecycle folders and the reference convention.
- Reference a plan by file name only, never with a folder path, so that moving it between state folders never changes any other file. Find a plan by searching (`doc/plan/**/<name>.md`), not by guessing the folder.
- When a plan is finished, move it to the done folder.
