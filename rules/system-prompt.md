# Plan Documents

- read `doc/plan/README.md` before creating, moving, renaming or referencing a plan; it defines the lifecycle folders and the reference convention.
- Reference a plan by file name only, never with a folder path, so that moving it between state folders never changes any other file. Find a plan by searching (`doc/plan/**/<name>.md`), not by guessing the folder.
- When a plan is finished, move it to the done folder.

# Themen-Nummern (D-xxx)

- Jedes D-Thema hat einen Kurzbezeichner: die Tabelle `doc/books/AdaptKey-Topics.md` ist die verbindliche
  Decodertabelle. Erwähne ein Thema immer als `D-xxx (Kurzbezeichner)`, nie als nackte Nummer. Im Chat
  für den Nutzer gern mit deutscher Übersetzung des Labels zitieren.
- **Kurzbezeichner sind auf Englisch zu ergänzen**, wie die übrigen Bücher. Die Erstbelegung 2026-11-21
  geschah fälschlich auf Deutsch — das ist als Fehlentscheidung markiert (siehe den Kopf von
  `AdaptKey-Topics.md`); die bestehenden deutschen Labels bleiben bis zu einer späteren Übersetzungs-
  Durchziehung stehen, neue Zeilen kommen ab sofort auf Englisch hinzu.
- Eine neue D-Nummer bekommt im selben Docs-Commit sofort eine Zeile in der Themenliste (inkl.
  Kurzbezeichner); die nächste freie Nummer steht am Ende der Datei.
- Einem Plan/Themenvorschlag dürfen nur freie Nummern zugewiesen werden; vor der Vergabe die Themenliste
  prüfen, nicht eine alte Notiz im Plan selbst.
